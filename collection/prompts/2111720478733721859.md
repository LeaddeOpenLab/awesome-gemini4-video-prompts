## Prompt (source language)

```text
Build a single-file index.html that shows a fluffy, furry 3D watermelon using Three.js loaded from a CDN (https://t.co/5A3fBgTy3A). Requirements:
- A watermelon with dark green stripes on a lighter green base, covered in realistic fur made with shell texturing, around 40 to 60 layers.
- Use a noise texture to control the fur strands, with fur getting thinner toward the tips.
- Soft lighting with highlights on the fur, and a pink background.
- OrbitControls so I can drag to rotate and scroll to zoom.
- A slow gentle swaying of the fur as if there were wind.
- Everything in one HTML file, with no build step and no external images. Output only the code.
```
