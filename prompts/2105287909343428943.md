## Prompt (English)

```text
I want to test your video creation capabilities. I want you to create a launch-style video (like when Anthropic launches a new feature) to use as an App Store preview video. Look up best practices and what converts best for these types of videos.

To create the video, use only JavaScript, Playwright, and FFmpeg. I added the hyperframes skill and you can use it if you deem it necessary. Be creative and fun, aligned with the communication we already use in the App.
```
