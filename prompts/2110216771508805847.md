## Prompt (source language)

```text
Create a self-contained HTML file featuring a pelican riding a bicycle.

Use inline SVG to create a seamless looping 2D animation in a polished flat illustration style.
The pelican should wear a red-and-white cycling cap and sunglasses. Give the bicycle a mint-green vintage frame, and add speed lines to emphasize motion.
Make the result complete, stylish, and ready for a public demo. Pay close attention to the bicycle geometry, character proportions, visual composition, and animation smoothness.

Use only HTML, CSS, and inline SVG, with no external dependencies. Output a single HTML file that can be opened directly in Chrome.
```
