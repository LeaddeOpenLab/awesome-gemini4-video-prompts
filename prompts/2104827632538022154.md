## Prompt (English)

```text
1. Import three@0.160.0 from CDN using importmap, without any build steps
2. Dark background, approximately 12,000 glowing particles smoothly morphing between three shapes: 'Sphere → Heart → HI text' every 4 seconds
3. For the text shape, draw text onto an offscreen canvas and sample particle positions without loading external fonts or images
4. Gradient colors across particles based on shape, additive blending for a glowing effect, slow overall self-rotation, with parallax tracking mouse movement
5. Display the current shape name in small text at the bottom right corner
```
