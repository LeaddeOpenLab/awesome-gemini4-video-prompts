## Prompt (source language)

```text
测试提示词：

请用 Three.js 编写一个单文件 HTML 页面，实现一个 3D 场景：「漂浮在云海上的蒸汽朋克天文台」。

【硬性约束】
- 单个 HTML 文件，Three.js 从 CDN 引入（固定版本号），不得加载任何外部模型、贴图或图片，所有几何体和纹理必须程序化生成
- 打开即可运行，无报错，桌面浏览器保持流畅（目标 60fps）

【场景内容】
1. 一座悬浮的岩石小岛，底部是不规则的岩石形态（不能是简单的圆锥或球体），岛上建有一座圆顶天文台
2. 天文台圆顶可以打开：圆顶上的一条狭缝向两侧滑开，露出一架望远镜
3. 天空中有一颗带光环的行星，沿椭圆轨道缓慢运动；望远镜必须始终实时对准这颗行星
4. 天文台旁边有一组外露的齿轮机构，至少 4 个齿轮，齿数各不相同。要求：相邻齿轮的齿真正啮合，转速比等于齿数的反比，相邻齿轮转向相反
5. 岛屿下方是云海，云层有缓慢的流动感
6. 昼夜循环（一个完整周期约 60 秒）：
   - 太阳的位置驱动主光源方向，阴影随之实时变化
   - 天空颜色随时间渐变（白天 → 黄昏 → 夜晚 → 黎明）
   - 夜晚出现星空，白天星星不可见
   - 黄昏时天文台的灯笼/窗户自动亮起，并照亮周围物体，黎明时熄灭

【交互】
- 鼠标拖拽旋转视角，滚轮缩放，视角有合理的限制（不能穿到岛屿内部或地底）
- 点击圆顶：切换开合状态，开合过程有平滑动画
- 屏幕角落有一个时间滑块，可以手动拖动时间，同时提供暂停/播放按钮

【画面要求】
- 统一的视觉风格，色彩协调，不要出现大面积纯色或默认材质
- 金属、岩石、玻璃等不同材质要有可区分的质感
```

### English translation (not author original)

```text
Test prompt:

Please write a single-file HTML page using Three.js to implement a 3D scene: 'A Steampunk Observatory Floating on a Sea of Clouds'.

[Hard Constraints]
- Single HTML file, Three.js imported via CDN (pinned version), no external models, textures, or images allowed; all geometry and textures must be procedurally generated.
- Ready to run upon opening without errors, maintaining smooth performance on desktop browsers (target 60fps).

[Scene Content]
1. A floating rocky island with an irregular rock bottom (not a simple cone or sphere), topped with a domed observatory.
2. The observatory dome can open: a slit on the dome slides open to both sides, revealing a telescope.
3. A ringed planet in the sky moving slowly along an elliptical orbit; the telescope must track and aim at this planet in real-time.
4. An exposed gear mechanism next to the observatory with at least 4 gears of different tooth counts. Requirements: adjacent gears truly mesh, gear ratios match inverse tooth counts, adjacent gears rotate oppositely.
5. A sea of clouds below the island with slow drifting motion.
6. Day-night cycle (full cycle ~60s):
   - Sun position drives primary light direction with dynamic shadows.
   - Sky color transitions smoothly (Day -> Dusk -> Night -> Dawn).
   - Stars appear at night, invisible during day.
   - Observatory lanterns/windows light up at dusk illuminating surroundings, turn off at dawn.

[Interactions]
- Mouse drag to rotate view, scroll to zoom, constrained perspective.
- Click dome to toggle open/close with smooth animation.
- Time slider in screen corner with pause/play button.

[Visual Requirements]
- Unified visual style, coordinated colors, distinguishable metal/rock/glass textures.
```
