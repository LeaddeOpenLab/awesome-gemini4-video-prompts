## Prompt (English)

```text
1. First give 3 style frames, 10s sample, 30s music preview, wait for my pick
2. On-screen text only uses my copy sheet
3. Split into subagents by chapter; each edits only their own file
4. Each segment outputs a contact sheet and seam frame-by-frame preview
5. Provide at least 3 music styles
6. Run self-checks on final film and write a report.
```
