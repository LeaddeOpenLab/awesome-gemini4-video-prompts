## Prompt (English)

```text
PROMPT:

Create a JavaScript animation showing how an LLM builds the context window with user questions and generated answers. Distinguish input from output context windows, which typically differ in size, and show output responses being transferred and appended to the input context. Make it clear and didactic, with Portuguese labels.

PROMPT 2:

Generate the animation in MP4 format for download.
```
