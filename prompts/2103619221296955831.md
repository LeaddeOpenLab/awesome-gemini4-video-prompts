## Prompt (English)

```text
"""
nice. we need a launch video for the release. can you do that? something like anthropic style? read something about it and the prompt was ""make a modern slick and punchy video for a modern startup that works on inference"
"""

"""
come on, surprise me! main thing is it goes viral
"""

"""
yeah where is the video? i only see a .cinfig file that is playable as a video
"""

"""
can we add some trendy background music to it?
"""
```
