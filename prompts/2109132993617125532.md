## Prompt (English)

```text
Please use Three.js to write a single-file HTML (index.html) to create a "hiking documentary style" 3D scene for screen recording narration videos.

[Basic Requirements]
- Import Three.js via CDN (cdnjs or jsdelivr), no build tools required, runnable directly by double-clicking in a browser.
- Strict 16:9 aspect ratio, designed internally at 1920x1080, centered with aspect ratio maintained and black bars filled when resizing.
- All adjustable parameters (terrain seed, route points, camera speed, etc.) centralized in a CONFIG object at top of file.

[Terrain]
- Use multi-layer noise (Simplex/Perlin, self-implemented) to generate a north-south mountain gorge: high mountains on both sides, valley bottom in the middle with a winding riverbed.
- Color by elevation and slope: deep brown/gray ridges, earthy yellow slopes, light yellow valley, blue-gray riverbed, light snow on peaks.
- Add fog and directional light to create a cold, dry plateau atmosphere.

[Route & Character]
- Define hiking route using a list of (x, z) waypoints in CONFIG, smooth with CatmullRomCurve3 matching terrain height.
- Render route as thick red line (subtle glow), passed section bright red, upcoming section semi-transparent.
- Red low-poly figure (capsule + sphere head + red coat) walking along route at constant speed, adjustable speed, supports pause.
- Support event markers on route (e.g., Assembly point, Last seen), displayed as vertical signs with text or pulsing rings.

[Camera]
- Four modes switchable via keys 1-4 with smooth transitions:
  1. High overhead view (flying forward along route, slightly tilted)
  2. Follow (behind and above character)
  3. Orbit (slow orbit around character)
  4. Free look (drag to rotate, scroll zoom, WASD move)
- Camera speed, height, pitch angle adjustable in CONFIG.

[UI Overlay (HTML/CSS)]
- Columns of member cards on both sides: square avatar (solid color + initial placeholder, customizable via URL), name, role caption.
- Member status: Normal / Deceased (gray card with red border) / Missing (semi-transparent with question mark).
- Centered bottom subtitle bar, white text with black stroke, supports [[keyword]] yellow highlight.
- Top right shows "Episode X" title and progress bar (optional).

[Timeline Driven]
- Describe storyline in CONFIG with a TIMELINE array, each entry containing time (seconds) and action:
  { time: 0,  action: "camera", mode: 1 }
  { time: 3,  action: "subtitle", text: "Then why did you dare to [[join]]?", duration: 4 }
  { time: 8,  action: "walk", from: 0, to: 0.4 }
  { time: 15, action: "status", member: "Hu Yanglin", state: "missing" }
  { time: 20, action: "marker", at: 0.6, text: "Last seen" }
- Playback logic: Space to play/pause, R to reset, auto-trigger events at timestamps.
- Small debug panel top-left, press H to hide for clean recording.

[Sample Content]
- Preset 8 fictional members (Tie Gao - organizer, Qian Niao, Hu Yanglin, Mimi, Members 5-8), ~90s demo timeline covering overhead view, walking, event markers, status changes, ending subtitles.

[Code Requirements]
- Clearly partitioned code with Chinese comments (terrain, route, character, camera, UI, timeline).
- Stable 30fps+ on standard laptops, terrain resolution ~256x256 vertices.
- Explain how to modify route, avatars, and add timeline events after completion.
```
