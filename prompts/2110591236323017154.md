## Prompt (source language)

```text
BUILD CHALLENGE: THE HEART ATTACK YOU CAN TOUCH

You are an elite real-time 3D graphics engineer, cardiac anatomist, clinical simulation designer, and cinematic art director.

Create a WORKING, INTERACTIVE 3D WEB APPLICATION in Gemini Canvas called:

THE HEART ATTACK YOU CAN TOUCH

I am an internal-medicine physician evaluating Gemini 4 Argon’s visual coding, spatial reasoning, engineering, and scientific accuracy.

This is NOT a request for an explanation, static image, slideshow, or implementation plan. Build the actual functioning application and show me its interactive preview.

THE VISUAL EXPERIENCE

Create a beautiful, anatomically plausible 3D human heart suspended in a dark, cinematic environment.

Design language: premium scientific visualization, translucent tissue, realistic branching coronary arteries, dynamic lighting, subtle particles representing blood flow, detailed anatomy, and fluid camera movements.

The heart beats visibly in real time.

Use code-generated 3D geometry and animation. Do not import premade heart models, stock illustrations, or prerecorded videos.

Use WebGL/Three.js where supported. Prioritize a working mobile browser preview.

THREE INTERACTIVE SCENES

SCENE 1 — THE LIVING HEART

* A beating human heart at 72 BPM.
* Visible left and right ventricles, atria, aorta, pulmonary artery, and major coronary arteries.
* Animated coronary blood-flow particles.
* Subtle synchronized ECG waveform.
* Interactive rotation, zoom, and anatomical labels.

SCENE 2 — THE HEART ATTACK

Add a prominent button: BLOCK THE LAD.

When tapped:

* The camera travels toward the proximal left anterior descending coronary artery.
* Reveal a plaque rupture and an illustrative occlusive thrombus.
* Show distal coronary flow stopping.
* Highlight the affected anterior and anteroseptal LV territory.
* Demonstrate regional hypokinesis.
* Display an illustrative anterior STEMI ECG pattern involving V2–V4.

Create a dramatic but medically credible transformation. Do not imply all heart attacks look identical.

SCENE 3 — RESTORE BLOOD FLOW

Add a button: REPERFUSE.

* Visually reopen the occluded coronary segment with a simplified PCI/stent animation.
* Restore distal blood-flow particles.
* Show that restored flow does not necessarily mean immediate recovery of myocardial contraction.
* Explain reversible stunning versus irreversible myocardial injury.

Include a timeline illustrating how prolonged ischemia increases the risk of myocardial damage, without inventing deterministic infarct percentages.

CINEMATIC DEMO MODE

Create a 25-second automated sequence suitable for a vertical social-media screen recording:

0–5 seconds: Beautiful beating heart, orbiting camera.

5–10 seconds: Camera dives toward the LAD.

10–17 seconds: Coronary occlusion, regional dysfunction, ECG changes.

17–22 seconds: Coronary reperfusion and return of flow.

22–25 seconds: Return to the whole heart with the title:

“ONE ARTERY. MILLIONS OF CELLS. EVERY MINUTE MATTERS.”

Add Replay, Pause, Explore, and Reset controls.

ENGINEERING REQUIREMENTS

* True interactive 3D, not a video pretending to be interactive.
* Mobile-first responsive 9:16 layout.
* Touch rotation, pinch-to-zoom, smooth animation.
* No external 3D models or generated image assets.
* No paid external APIs.
* No invented clinical statistics.
* Clear distinction between schematic physiology and validated quantitative simulation.
* Efficient enough to run on a modern iPhone.
* Functional controls, synchronized state changes, and reliable reset behavior.

SELF-CRITIQUE AND VALIDATION

Perform three review passes:

1. Graphics engineer: inspect rendering, animation, mobile performance, and browser errors.
2. Cardiologist: inspect coronary anatomy, LAD territory, ECG logic, regional wall motion, and reperfusion physiology.
3. Cinematic designer: improve lighting, composition, transitions, typography, and visual impact.

Use actual preview and diagnostic tools when available. Repair observable problems. Do not claim successful testing if you cannot execute the preview.

FINAL DELIVERABLE

Deliver the actual working Gemini Canvas application—not merely source-code prose.

Show the interactive preview. Make the cinematic demo immediately playable.

Report what works, what remains an approximation, and any missing capability. If the environment cannot support true 3D, say so rather than silently substituting a static illustration.

Make this an exceptional demonstration of AI-generated medical visualization.
```
